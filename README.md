# P_rapae_thermalchallenge
This repository contains scripts used to analyze RNA-sequencing data on Pieris rapae caterpillar samples under thermal challenge. The vast majority of these scripts were adapted from Samantha Sturiale, since we both worked on ecology and evolution in the same species (https://github.com/samstur/P_rapae_RNASeq/blob/main/MasterNotes.md). 

This research also compares DEseq2 data with hers, so we diverge in the questions we were trying to answer.
